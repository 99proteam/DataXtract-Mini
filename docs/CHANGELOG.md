# Data Extractor Pro - Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-01-01

### Added
- **Google Maps Extractor** - Extract business data with phone, email, website, hours, reviews
- **Domain Extractor** - Bulk domain data extraction from .txt files
- **Campaign System** - Organize and manage extraction campaigns
- **Email Marketing** - SMTP-based bulk email campaigns with templates
- **SMS Marketing** - Twilio-powered SMS campaigns
- **WhatsApp Web Integration** - Browser-based WhatsApp messaging
- **LinkedIn Sales Navigator** - People and job search extraction
- **Email Verification** - Multi-method email validation (ZeroBounce, SMTP, MX)
- **Bulk Screenshots** - Capture multiple website screenshots
- **AI Integration** - OpenAI and Google Gemini support
- **Proxy Support** - Webshare.io API integration
- **User Agent Rotation** - Anti-blocking measures
- **Export Formats** - CSV, JSON, Excel export options
- **Real-time Updates** - WebSocket-based progress tracking
- **Premium UI** - Dark theme with glassmorphism design

### Features
- Multi-channel marketing (SMS, Email, WhatsApp)
- Campaign-based workflow
- Real-time extraction progress
- Comprehensive settings panel
- Info icons with tooltips for all options
- Responsive design
