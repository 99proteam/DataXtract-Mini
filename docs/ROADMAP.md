# DataXtract Mini roadmap

This roadmap communicates direction rather than guaranteed dates. Community feedback and pull requests can change priorities.

## Near term

- Expand automated route and service tests.
- Add sample import files and anonymized export examples.
- Improve first-run configuration checks and error messages.
- Add clearer progress, cancellation, and retry states for long-running jobs.
- Document platform-specific browser troubleshooting.

## Next

- Add campaign templates and reusable extraction presets.
- Improve export field mapping and duplicate handling.
- Add configurable retention controls for local data and session files.
- Add accessibility and keyboard-navigation improvements.
- Add container-based deployment documentation.

## Future ideas

- Plugin-style integration boundaries.
- Additional consent and suppression-list controls for outreach.
- Structured audit logs for locally initiated jobs.
- Localization support.

Suggest or discuss priorities in [GitHub Discussions](https://github.com/99proteam/DataXtract-Mini/discussions).
