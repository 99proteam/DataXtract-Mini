Install it free

How to install (5 minutes)

No coding knowledge needed. Follow these steps once. After that, starting the app takes one command.

1

Install Node.js and Chrome

Node.js is the free program that runs DataXtract. Download the LTS version and click Next through the installer. You also need Google Chrome or Microsoft Edge (you probably have one already).

Download Node.js ↗ Download Chrome ↗
2

Download DataXtract Mini

Download the ZIP file, then right-click it and choose Extract All (on Mac, just double-click it). You will get a folder named DataXtract-Mini-main.

⬇ Download ZIP
3

Open a terminal in that folder

A terminal is a window where you type commands. Pick your computer:

  1. Open the DataXtract-Mini-main folder in File Explorer.
  2. Click the address bar at the top, type cmd and press Enter.
  3. A black window opens, already inside the folder.
  1. Open Finder and find the DataXtract-Mini-main folder.
  2. Right-click the folder and choose New Terminal at Folder.
  3. If you don't see it: open Terminal, type cd and a space, drag the folder into the window, then press Return.
  1. Open the DataXtract-Mini-main folder in your file manager.
  2. Right-click inside it and choose Open in Terminal.
4

Install and start (one command)

Copy this, paste it into the terminal and press Enter. The first time takes a few minutes while it downloads what it needs.

npm run deploy

Leave this window open while you use the app. Closing it stops DataXtract.

5

Open the app in your browser

When the terminal says Server running, open this address:

http://127.0.0.1:3007

Click New Campaign, enter a search like “cafe in London”, press Start and watch the leads come in.

↻

Next time

Open a terminal in the same folder (step 3) and run:

npm start

Common questions

Stuck? These fix most problems.

Do I have to pay for hosting?

No. DataXtract runs on your own computer, so there is no hosting bill. You only pay if you choose to put it on an online server (around $5–10/month) so it runs 24/7 for other people.

Can I extract real data on this website?

No. The live demo only shows sample data. Real extraction needs the app installed on your computer (steps above).

“npm is not recognized” or “command not found”

Node.js is not installed yet, or the terminal was open before you installed it. Install Node.js (step 1), close the terminal, then open a new one (step 3).

“Port 3007 already in use”

DataXtract is probably already running in another terminal window. Use that one, or close it and run npm start again.

“Could not find Chrome” or the browser does not start

Install Google Chrome or Microsoft Edge, then run npm start again. If your antivirus blocks Chrome, allow Chrome and Node.js in its settings.

Do I need API keys or accounts?

Not for basic extraction. Email sending (SMTP), SMS (Twilio), email checking (ZeroBounce), AI and proxies are optional extras you can add later in Settings.
